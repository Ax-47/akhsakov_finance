# AI connector และพอร์ตเงินสมมติ

Akhsakov Finance เปิด MCP server แบบ provider-neutral ที่ `/mcp` ผู้ช่วย AI ตัวใดที่รองรับ Streamable HTTP MCP สามารถอ่านพอร์ตและ thesis, เพิ่มบันทึก และจัดการพอร์ตเงินสมมติได้

## เปิดใช้ MCP

1. เปิด **Settings → MCP connections** แล้วสร้าง connection ตั้งชื่อ เลือกสิทธิ์ และเลือกพอร์ตอย่างน้อยหนึ่งพอร์ต
2. คัดลอก secret ตอนสร้างหรือ rotate ทันที แอปจะแสดงเพียงครั้งเดียวและเก็บเฉพาะ hash
3. ใส่ที่อยู่ที่ไคลเอนต์เข้าถึงได้ ไคลเอนต์บนคลาวด์ต้องใช้ HTTPS ส่วนไคลเอนต์บนเครื่องเดียวกันใช้ `http://127.0.0.1:8080` ได้
4. เลือกตัวอย่าง Generic, Claude, Codex, Antigravity / `agy`, Cursor / VS Code หรือ Other แล้วคัดลอกค่าที่แสดง

ตัวเลือกเหล่านี้เป็นเพียงตัวอย่างการตั้งค่า ทุกตัวเชื่อมต่อ endpoint เดียวกัน ชุดเครื่องมือและข้อมูลที่เห็นขึ้นกับ preset และพอร์ตของ connection ไม่ใช่ชื่อไคลเอนต์หรือผู้ให้บริการโมเดล

### รูปแบบทั่วไป

- URL: `https://<server>/mcp`
- Header: `Authorization: Bearer <key>`
- สำหรับไคลเอนต์ที่ตั้ง header ไม่ได้: `https://<server>/mcp/<key>`

### ตัวอย่างไคลเอนต์

- Claude Code: ใช้คำสั่ง `claude mcp add --transport http ... --header "Authorization: Bearer ..."` ที่หน้า Settings สร้างให้
- Codex: เพิ่ม `[mcp_servers.akhsakov]` พร้อม `url` และ `http_headers` ลง `~/.codex/config.toml`
- Antigravity / `agy`: เพิ่ม `serverUrl` และ `Authorization` ใต้ `mcpServers` ใน `.agents/mcp_config.json` หรือไฟล์ global
- Cursor / VS Code: เพิ่ม HTTP server ในไฟล์ MCP JSON ของไคลเอนต์

## เครื่องมือ MCP

| เครื่องมือ | การทำงาน |
|---|---|
| `list_portfolios` | อ่านรายชื่อพอร์ตและหุ้นที่ถือ |
| `list_theses` | อ่าน thesis และรายการที่ยังไม่มี thesis |
| `get_thesis` | อ่าน thesis, บันทึกติดตาม และสถานะของหุ้นหนึ่งตัว |
| `save_thesis` | สร้างหรือแก้ thesis เมื่อผู้ใช้ขอหรือยืนยัน |
| `add_thesis_note` | เพิ่มบันทึกติดตามโดยระบุผู้เขียนเป็น AI |
| `get_quote` | อ่านราคาล่าสุด |
| `get_my_portfolio` | อ่านพอร์ตเงินสมมติที่ AI จัดการ |
| `get_my_goals` | อ่านเป้าหมายของพอร์ตเงินสมมติที่ AI จัดการ (แก้ไม่ได้) |
| `place_order` | ซื้อขายเฉพาะในพอร์ตเงินสมมติ พร้อมบันทึกเหตุผล |
| `list_transactions` | อ่านรายการซื้อขาย ปันผลที่ได้รับ ฝาก/ถอน กรองตามพอร์ต ประเภท และวันที่ได้ |
| `list_watchlists` | อ่าน watchlist, บันทึกและ tag ของหุ้น และการแจ้งเตือนราคา |
| `get_goals` | อ่านเป้าหมายของพอร์ตผู้ใช้ พร้อมดูว่าทันเป้าไหม |
| `get_price_history` | อ่านราคาปิดย้อนหลัง 1 เดือนถึงทั้งหมด |
| `get_fundamentals` | อ่านข้อมูลพื้นฐาน เช่น P/E ปันผล และราคาเป้าหมายของนักวิเคราะห์ |
| `get_calendar` | อ่านวันประกาศงบและวัน XD ที่จะถึง |
| `add_to_watchlist` | เพิ่มหุ้นลง watchlist พร้อมบันทึก เมื่อผู้ใช้ขอหรือยืนยัน |
| `create_alert` | ตั้งการแจ้งเตือนราคา เมื่อผู้ใช้ขอหรือยืนยัน |

### Prompts

ไคลเอนต์ที่รองรับ MCP prompts จะเห็นคำสั่งสำเร็จรูป 2 อัน:

- `monthly_review`: ทบทวนพอร์ตประจำเดือน (รายการเดือนนี้, thesis, เป้าหมาย, งบและ XD ที่จะถึง)
- `theses_due`: ไล่ thesis ที่ถึงวันทบทวนทีละตัว

ทั้งสองอันระบุพอร์ตได้ และไม่แก้ข้อมูลเองจนกว่าผู้ใช้จะยืนยัน

## Model connections

Settings รองรับ profile ของ API ที่เข้ากันได้กับ OpenAI Chat Completions โดยกรอกชื่อ, API base URL, model identifier และ API key เอง ไม่มี preset หรือโค้ดเฉพาะผู้ให้บริการ

แต่ละ profile ตั้งค่าเพิ่มได้:

- **เวลารอคำตอบแต่ละครั้ง** (1–600 วินาที, ค่าเริ่มต้น 45) สำหรับโมเดลที่คิดนาน การกด Run AI trader จะให้เวลาทั้งรอบอย่างน้อย 2 เท่าของค่านี้ (ไม่ต่ำกว่า 2 นาที) ส่วนใน race ยังใช้เส้นตายของรอบ
- **จำนวน token สูงสุดต่อคำตอบ** ส่งเป็น `max_tokens` เว้นว่างไว้เพื่อใช้ค่าของผู้ให้บริการ
- **header ที่ใช้ส่ง API key** เว้นว่างไว้คือ `Authorization: Bearer <key>` ถ้าใส่ชื่ออื่น เช่น `api-key` หรือ `x-api-key` แอปจะส่ง key ตรงๆ ใน header นั้น
- **header เพิ่มเติม** บรรทัดละตัวในรูป `ชื่อ: ค่า` (สูงสุด 10 ตัว) เก็บแยกคู่กับ API key ไม่แสดงค่ากลับในหน้าจอ ไม่อยู่ใน backup และถูกปิดบังถ้าผู้ให้บริการส่งกลับมาในข้อความ error

เลือก profile และกำหนดกลยุทธ์ให้พอร์ตเงินสมมติ แล้วกด **Run AI trader** แอปจะส่งเฉพาะข้อมูลพอร์ตนั้นให้โมเดลและอนุญาตให้ซื้อขายเฉพาะพอร์ตนั้น รายการซื้อขายเกิดขึ้นทันทีด้วยเงินสมมติและเก็บ audit log ไว้

โมเดลใช้ tool ได้ 8 ตัว: `list_theses`, `get_thesis`, `save_thesis`, `add_thesis_note`, `get_my_portfolio`, `get_my_goals`, `get_quote` และ `place_order` ทุกตัวถูกบังคับให้ใช้กับพอร์ตของ trader เองเสมอ แม้โมเดลจะระบุพอร์ตอื่นมา trader แก้ thesis ของพอร์ตตัวเองได้โดยไม่ต้องถาม (บันทึกใน journal ว่า AI เขียน) และอ่านเป้าหมายที่ผู้ใช้ตั้งให้พอร์ตนั้นได้ แต่แก้เป้าหมายไม่ได้

ตั้ง **กรอบการลงทุน** ให้แต่ละพอร์ตได้ข้างกลยุทธ์: ระยะเวลาลงทุน (ปี), ยอมให้ลดลงจากจุดสูงสุดได้มากสุดกี่ %, และดัชนีที่ต้องการชนะ ทุกครั้งที่เริ่มรัน trader จะได้รับกรอบนี้พร้อมเป้าหมายของพอร์ต (มูลค่าตอนนี้, ตามเป้าหรือไม่, ผลตอบแทนที่ยังต้องการ) ใน prompt

หรือเลือก **MCP connection** แทน profile (ต้องเปิดใช้งาน ใช้ preset `trader` และเข้าถึงพอร์ตนั้นได้) พอร์ตจะถูกขับโดยไคลเอนต์ MCP ภายนอก จึงไม่มีปุ่ม Run AI trader แต่ละพอร์ตเลือกได้อย่างใดอย่างหนึ่งเท่านั้น

### รันตามเวลา

พอร์ตที่ใช้ profile ของโมเดลตั้งให้รันเองได้ที่ Settings → AI paper portfolios: ทุกกี่ชั่วโมง (1–168), วันไหนบ้าง และจะรันเวลาใดก็ได้ หรือเฉพาะตอนตลาดสหรัฐฯ เปิด (9:30–16:00 เวลานิวยอร์ก) หรือตลาดหุ้นไทยเปิด (10:00–16:30) เซิร์ฟเวอร์เช็กทุกนาที และจองรอบถัดไปในฐานข้อมูลก่อนรัน จึงไม่รันซ้ำหลังรีสตาร์ท ถ้าแอปปิดไปหลายรอบจะรันแค่ครั้งเดียว รอบที่ถึงเวลาตอนเปิดหยุดฉุกเฉินหรือพอร์ตอยู่ใน race จะถูกข้ามพร้อมบอกเหตุผล (ไม่นับวันหยุดตลาด)

### แจ้งเตือน

การ์ด AI paper portfolios ใน Settings เลือกได้ว่าจะแจ้งเตือนเรื่อง AI แค่ไหน ผ่านช่องทางเดียวกับ alert ราคา (ในแอป, ntfy, Telegram, webhook):

- **เฉพาะตอนมีอะไรล้มเหลว** (ค่าเริ่มต้น): การรันที่ล้มเหลว, รอบของ race ที่มีผู้แข่งล้มเหลว (รวมเป็นข้อความเดียวต่อรอบ), race ที่ถูกพักเพราะ error หรือแอปรีสตาร์ท
- **ตอนล้มเหลว, ตอนซื้อขาย และผล race**: เพิ่มการรันที่ซื้อขาย (จำนวนและสรุปบรรทัดแรก) และ race ที่จบพร้อมผู้ชนะ
- **ไม่ต้องแจ้ง**

การรันที่ถูกหยุดด้วยปุ่มหยุดฉุกเฉินจะไม่แจ้งเตือน

### หยุดฉุกเฉิน

ปุ่ม **หยุด AI ทั้งหมด** อยู่บนหน้า AI races และการ์ด AI paper portfolios ใน Settings (กดสองครั้งเพื่อยืนยัน) เมื่อเปิด แอปจะหยุดการรันของ AI ที่กำลังทำอยู่ทันที พัก race ที่กำลังแข่ง และปฏิเสธ `place_order` ทุกทาง ทั้งจากโมเดลที่แอปเรียกเองและจากไคลเอนต์ MCP เริ่มรันหรือทำ race ต่อไม่ได้จนกว่าจะปิด สถานะนี้เก็บในฐานข้อมูลจึงยังอยู่หลังรีสตาร์ท และบันทึกว่าใครเปิดหรือปิดเมื่อไร เมื่อปิดแล้ว race ที่ถูกพักต้องกดทำต่อเอง

### AI race กับไคลเอนต์ MCP

การแข่งขันผสมผู้เข้าแข่งขันทั้งสองแบบได้ แอปปลุกไคลเอนต์ MCP ไม่ได้ ดังนั้นทุกรอบจะเปิด **round window** ให้ผู้เข้าแข่งขันแบบ MCP ด้วยราคาที่ถูกตรึงชุดเดียวกันและเส้นตายเดียวกับโมเดลอื่น ระหว่างการแข่งขัน `get_my_portfolio` จะมีฟิลด์ `race` (`round`, `window_open`, `deadline` หรือ `next_round_at`) ไคลเอนต์ควรตั้งเวลาเรียกบ่อย ๆ (เช่น `/loop`) และส่ง `place_order` เฉพาะตอน `window_open` เป็น `true` นอก window คำสั่งจะถูกปฏิเสธ และรอบที่ไม่มีการเรียกเครื่องมือสำเร็จเลยนับเป็น failed run พอร์ตที่อยู่ในการแข่งขันยังถูกปิดไม่ให้ MCP connection อื่นซื้อขาย และแก้ไขหรือลบ MCP connection ที่ขับผู้เข้าแข่งขันไม่ได้จนกว่าการแข่งขันจะจบ

แต่ละพอร์ตมี persistent memory แยกกัน โดยเก็บสรุปการตัดสินใจและคำถามที่ยังไม่ได้ข้อสรุปเพื่อส่งให้รอบถัดไป ผู้ใช้ตรวจ แก้ไข หรือล้าง memory ได้ใน Settings และกำหนดทั้งขนาด memory กับ context window ของโมเดลได้ เมื่อบทสนทนาในรอบปัจจุบันใกล้เต็ม context แอปจะตัดรอบเรียกเครื่องมือเก่าออกเป็นชุด โดยคง system prompt, memory และรอบล่าสุดไว้

## ความปลอดภัย

- ไม่มีไคลเอนต์ภายนอกเข้าถึงได้จนกว่าจะสร้าง connection และทุกคำขอต้องมี secret ของ connection ที่ยังเปิดใช้
- แต่ละ connection มี secret, preset และขอบเขตพอร์ตของตัวเอง ปิด ลบ หรือ rotate connection หนึ่งได้โดยไม่กระทบ connection อื่น
- `read_only` อ่านพอร์ต, thesis, รายการซื้อขาย, เป้าหมาย, watchlist และข้อมูลตลาด; `thesis_editor` เพิ่มการแก้ thesis/บันทึก, เพิ่มหุ้นลง watchlist และตั้งการแจ้งเตือน; `trader` เพิ่ม paper order เฉพาะ AI paper portfolio ที่อนุญาต
- แต่ละ connection เรียกได้ไม่เกิน 120 ครั้งต่อนาที เกินจากนั้นจะได้ HTTP 429 ให้รอสักครู่แล้วลองใหม่
- ทุกการเรียกถูกบันทึกไว้ใน audit ของ connection นั้น (500 รายการล่าสุด) ดูได้ใน Settings
- ถ้า secret หลุดให้ rotate connection นั้นทันที
- API key ถูกเก็บแยก ไม่แสดงกลับใน UI และไม่รวมในไฟล์ backup
- Trader memory เป็นข้อมูลของพอร์ตและรวมอยู่ใน backup แต่ไม่เก็บ API key หรือ MCP key
- พอร์ตเงินสมมติไม่นับรวมยอด, รายงาน, ภาษี หรือการแจ้งเตือนของพอร์ตจริง
- การหยุด AI trading ไม่ลบพอร์ตหรือประวัติ
