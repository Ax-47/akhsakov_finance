## ฟีเจอร์ที่มีแล้ว

### 1. Dashboard (หน้าแรก)
- มูลค่าพอร์ตรวมแบบสด (ตัวเลขหมุนแบบมาตรวัดเมื่อราคาเปลี่ยน) และการเปลี่ยนแปลงวันนี้
- คำตอบด่วน: หุ้นที่ขยับมากสุดวันนี้, เงินกระจุกอยู่ที่ไหน, กี่ตัวที่เป็นบวก
- เตือนเมื่อหุ้นตัวเดียวมีสัดส่วนเกินเกณฑ์ในพอร์ต
- เหตุการณ์ที่ใกล้มาถึง (งบ/ปันผล) จากปฏิทิน

### 2. พอร์ตโฟลิโอ
- หลายพอร์ต: สร้าง / เปลี่ยนชื่อ / ลบ, ดูรวมทุกพอร์ตหรือทีละพอร์ต (dropdown ค้นหาได้)
- รายการธุรกรรม: Buy, Sell, Dividend, Split, Transfer, Deposit, Withdrawal (เงินสดใช้ ticker `$CASH`)
- ทุกธุรกรรมมี **ค่าธรรมเนียม** และ **สกุลเงิน** พร้อมอัตราแลกเปลี่ยน ณ วันเทรด (เติมให้อัตโนมัติถ้าไม่ได้ใส่)
- แท็บในหน้าพอร์ต:
  - **Overview**: ตารางถือครอง, กราฟสัดส่วนสินทรัพย์, กราฟผลตอบแทน
  - **Income**: ปันผลที่ได้รับและที่คาดว่าจะได้, หุ้นแต่ละตัวช่วยสร้างกำไรเท่าไร (ทั้งหมด / วันนี้)
  - **Risk**: ย้อนหลัง 3 เดือน / 1 / 2 / 5 ปี คิดเป็นสกุลเงินที่เลือกแสดง (รวมเงินสดได้), ความผันผวน (รวมค่าล่าสุดแบบ EWMA), VaR / Expected shortfall พร้อมทดสอบย้อนหลัง (Kupiec), stress test ตาม beta, วิกฤตในอดีต (2008, 2011, 2018, โควิด, 2022), risk contribution + จำนวนวันที่ใช้ขาย (สภาพคล่อง), สัดส่วนตามสกุลเงิน / เซกเตอร์ / ประเทศ, เทียบกับ benchmark (กราฟ 100 + drawdown), กราฟความสัมพันธ์ (correlation), การกระจายความเสี่ยง (ตามน้ำหนัก + จำนวนการลงทุนที่อิสระต่อกัน), การ์ด CAPM (beta แก้เองได้, ผลตอบแทนปรับเป็นต่อปีตามระยะเวลาที่ถือ), ปุ่มตั้งแจ้งเตือนเมื่อขาดทุนเกิน VaR
  - หุ้นที่ซื้อขายคนละตลาด (เช่น ไทยกับสหรัฐฯ) เทียบกันแบบเหลื่อม 1 วัน (Dimson) เพราะตลาดปิดคนละเวลา
  - **Plan**: Rebalance ตามน้ำหนักเป้าหมาย, **แผนลงทุนรายเดือน (DCA)**, ภาษีแบบ FIFO tax lots (กำไรที่รับรู้แล้ว + ระยะเวลาถือ), **ภาษีไทย**, ผลตอบแทนแบบ money-weighted, เป้าหมายการเงินพร้อมการคาดการณ์
  - **Thesis**: เหตุผลที่ถือหุ้นแต่ละตัวในแต่ละพอร์ต, เงื่อนไขขาย, ราคาเป้าหมาย, ความมั่นใจ 1–5, วันทบทวน, สถานะ และบันทึกติดตามที่มีวันที่กำกับ
  - **Activity**: **รายงานประจำเดือน**, ประวัติธุรกรรม เพิ่ม / แก้ / ลบ
  - **Overview** มีการ์ด **กองทุน ทองคำ และสินทรัพย์อื่น** (ดูข้อ 15)

### 3. หน้าหุ้นรายตัว (`/stock/:ticker`)
- ราคา, ข้อมูลสำคัญ, บรรทัด "คุณถือ …" ถ้าถืออยู่
- กราฟเทคนิคัล: แท่งเทียนหรือเส้น, SMA/EMA, Bollinger Bands, Volume, RSI หรือ MACD (ราคาที่ซื้อขายจริงในสกุลเงินของหุ้น)
- แท็บ: Summary, Statistics, Financials (งบการเงิน), Analysis (ผลตอบแทนช่วงต่างๆ, ความเสี่ยงเทียบตลาด, 52-week range, เทรนด์/โมเมนตัม), News, Ownership (ผู้ถือหุ้นใหญ่), Options, Compare (เทียบกับหุ้นคู่แข่ง)
- เรทติ้งนักวิเคราะห์, ประวัติปันผลและการแตกหุ้น
- โน้ตและแท็กส่วนตัวต่อหุ้น, thesis ของหุ้นตัวนั้นในแต่ละพอร์ต, ปุ่ม ☆ เพิ่มเข้า watchlist

### 4. ตลาด (Markets)
- ดัชนี S&P 500, Nasdaq-100, Dow, SET50 แสดงเป็น heatmap ตามเซกเตอร์
- Market breadth, การเคลื่อนไหวรายเซกเตอร์, หุ้นขึ้น/ลงแรงสุดของวัน, ตารางหุ้นตามเซกเตอร์

### 5. Screener
- กรองหุ้นตามเซกเตอร์, ขนาดบริษัท, valuation, dividend yield, การเคลื่อนไหววันนี้
- มี preset กดครั้งเดียว

### 6. ปฏิทิน
- วันประกาศงบและวันปันผลของหุ้นที่ถือและที่ติดตาม

### 7. เศรษฐกิจ (Economy)
- มาตรวัดตลาด, ตัวชี้วัดเศรษฐกิจมหภาคของสหรัฐฯ, Yield curve พันธบัตรสหรัฐฯ (วันนี้เทียบปีก่อน)

### 8. เรียนรู้ (`/learn`)
- บทเรียนสั้นๆ 2 หลักสูตร ภาษาไทย/อังกฤษ
  - **วิเคราะห์หุ้น** (6 บท): เข้าใจธุรกิจ, อ่านงบการเงิน, valuation (P/E, PEG, P/B, EV), คุณภาพและนักวิเคราะห์, อ่านกราฟเทคนิคัล, เช็กลิสต์ก่อนซื้อ
  - **เข้าใจความเสี่ยง** (8 บท): ประเภทความเสี่ยง, ความผันผวน, drawdown, VaR / expected shortfall, beta และ correlation, Sharpe / Sortino / alpha, กระจายความเสี่ยงและกำหนดขนาดการลงทุน, จัดการความเสี่ยงในชีวิตจริง
- เครื่องคำนวณในบทเรียน: P/E และ PEG, ช่วงผลตอบแทนหนึ่งปีจากความผันผวน, ต้องกำไรเท่าไรถึงคืนทุน, VaR, จำลองตลาดร่วงด้วย beta, เทียบ Sharpe, ผสมสองสินทรัพย์ตาม correlation, ขนาดการลงทุนจากเงินที่ยอมเสียได้
- ปุ่ม "ดูของจริงในแอป" พาไปแท็บที่เกี่ยวข้อง (เช่น แท็บ Risk ของพอร์ต, แท็บงบการเงินของหุ้น)
- คำถามทบทวนท้ายบท ตอบถูกแล้วติ๊ก ✓ และนับความคืบหน้าของแต่ละหลักสูตร (จำไว้ในเครื่อง)
- ลิงก์ลัดจากการ์ด Risk overview และตาราง Valuation measures มาที่บทเรียนที่ตรงกัน

### 9. Backtest
- จำลองพอร์ตหลายตัวแบบลงเงินก้อนและ/หรือ DCA รายเดือน เทียบกับ benchmark

### 10. Watchlist และแจ้งเตือนราคา
- หลาย watchlist ตั้งชื่อได้, ราคาสด, แท็กจากโน้ต
- Alert 14 แบบ: ราคาขึ้นถึง, ราคาลงถึง, ขยับเกิน X% ในวัน, สัดส่วนในพอร์ตเกิน X%, ทั้งพอร์ตลดลงเกิน X% ในวัน, ทั้งพอร์ตลดลงจากจุดสูงสุดเกิน X%
- Alert ทางเทคนิคัล: RSI (14) สูง/ต่ำกว่าเกณฑ์, ราคาตัดขึ้น/ลงเส้น SMA (กี่วันก็ได้ 2–250), เข้าใกล้ 52-week high/low ภายใน X%, ประกาศงบภายใน N วัน, วัน XD ภายใน N วัน (เซิร์ฟเวอร์ใช้ราคารายวัน 1 ปีและปฏิทินงบ/ปันผล)
- เซิร์ฟเวอร์เช็กทุกนาทีแม้ไม่ได้เปิดแอป, เด้ง toast ในแอป และส่งออกไปที่ ntfy / Telegram / webhook (Slack, Discord ฯลฯ)

### 11. ข้อมูลเข้า-ออก
- **Import CSV** จากโบรกเกอร์ (จับคอลัมน์ตามชื่อหัวตาราง, รองรับ `,` `;` tab)
  - preset สำหรับ **Streaming (Settrade)**, **Dime!**, **Webull**, **Interactive Brokers** ใช้ไฟล์ export ได้เลยโดยไม่ต้องแก้หัวตาราง: หัวตารางภาษาไทย, วันที่แบบ วัน/เดือน/ปี และปี พ.ศ., เติม `.BK` และสกุล THB ให้หุ้นไทย, ข้ามคำสั่งที่ไม่ได้จับคู่ (Webull), อ่านเฉพาะส่วน Trades ของ Activity statement (IBKR, ตรวจจับให้เองในโหมด Auto) และ Flex query
- **Export CSV** ธุรกรรมและรายการถือครอง
- คัดลอกไปคลิปบอร์ด, พิมพ์ / บันทึกเป็น PDF (ธีมสว่าง)
- **รายงานประจำเดือน** (แท็บ Activity): มูลค่าต้นเดือน → สิ้นเดือน, เงินที่ลงเพิ่ม, กำไรจากตลาดและผลตอบแทนของเดือน, ปันผลและภาษี, ค่าธรรมเนียม, จำนวนซื้อ/ขาย, หุ้นที่ขึ้น/ลงมากสุด เลือกย้อนหลังได้ 12 เดือน ดาวน์โหลดเป็นข้อความ พิมพ์เป็น PDF หรือกด "ส่งตอนนี้" และตั้งให้ส่งรายงานเดือนก่อนเข้า ntfy / Telegram / webhook อัตโนมัติทุกวันที่ 1
- Backup ดาวน์โหลด และ Restore

### 12. AI connector และ model connections
- MCP server แบบ provider-neutral ที่ `/mcp` ใช้กับไคลเอนต์ที่รองรับ Streamable HTTP พร้อมตัวอย่าง Generic, Claude, Codex, Antigravity / `agy`, Cursor / VS Code และ Other
- บันทึก profile ของ API ที่เข้ากันได้กับ OpenAI Chat Completions ได้หลายชุด โดยไม่มี preset หรือโค้ดเฉพาะผู้ให้บริการ
- พอร์ตเงินสมมติของ AI เลือก profile และกลยุทธ์ได้ กด Run AI trader เพื่อให้โมเดลดู thesis/ราคาและซื้อขายเฉพาะพอร์ตนั้น พร้อม audit log
- เปิด/ปิด MCP และสร้างคีย์ใหม่ได้ใน Settings สิ่งที่ AI เขียนมีป้าย AI กำกับ วิธีตั้งค่าอยู่ใน [AI_CONNECTOR.md](AI_CONNECTOR.md)

### 14. การตั้งค่าและการใช้งาน
- สกุลเงินแสดงผล 13 สกุล (USD, THB, EUR, GBP, JPY, CNY, HKD, SGD, AUD, CAD, CHF, KRW, INR)
- อัตราดอกเบี้ยไร้ความเสี่ยง, benchmark, ผลตอบแทนที่สมมติสำหรับเป้าหมาย
- ภาษาไทย / อังกฤษ, ธีม Catppuccin (Latte / Mocha ตามเครื่อง)
- โหมด Lite สำหรับเครื่องช้า (ปิดแอนิเมชัน, อัปเดตราคาห่างขึ้น)
- คีย์ลัดแบบ Vim (กด `?` ดูรายการ, ใช้ได้กับแป้นไทย)
- ค้นหาหุ้นด้วยชื่อหรือ symbol
- แคชหน้า (กลับมาหน้าเดิมเห็นข้อมูลทันที), แคชราคาใน SQLite ฝั่งเซิร์ฟเวอร์, กราฟใช้งานได้แบบออฟไลน์ (ไฟล์ ECharts ฝังในแอป)
- **โหมดออฟไลน์**: พอร์ต ธุรกรรม การตั้งค่า ราคาล่าสุด ข้อมูลหน้า (สูงสุด 80 หน้า) และประวัติราคาสำหรับกราฟ ถูกเก็บในเครื่อง (local storage) ถ้าเซิร์ฟเวอร์หรืออินเทอร์เน็ตใช้ไม่ได้ แอปยังเปิดได้และแสดงข้อมูลล่าสุดพร้อมแถบ "ออฟไลน์" บอกเวลาที่บันทึก ข้อมูลที่ดึงไม่สำเร็จจะไม่ทับข้อมูลเดิม และถูกล้างเมื่อออกจากระบบ

### 15. สินทรัพย์ประเภทอื่น
- ระบุประเภทของแต่ละ ticker: หุ้น, ETF, กองทุนรวม, คริปโต, ทองคำ, พันธบัตร, เงินฝาก, เงินสด พร้อมชื่อ
- **กรอกราคาเอง** สำหรับสินทรัพย์ที่ Yahoo ไม่มีราคา (กองทุนรวมไทย, เงินฝาก, พันธบัตร, ทองคำแท่ง): ตั้งรหัสเอง เช่น `KFSSF` แล้วกรอก NAV/ราคาเป็นระยะ แอปใช้ราคาล่าสุดเป็นราคาปัจจุบันและสร้างกราฟรายวันจากราคาที่กรอก จึงใช้กับพอร์ต กราฟ ความเสี่ยง รายงาน และ alert ได้เหมือนหุ้นทั่วไป
- คริปโต (`BTC-USD`) และทองคำ (`GC=F`) ใช้ราคาตลาดจาก Yahoo ได้เลย
- ระบุกองทุนเป็น **SSF / RMF / Thai ESG** เพื่อติดตามสิทธิลดหย่อน

### 16. ภาษีไทย (แท็บ Plan)
- สรุปรายปีภาษีเป็นเงินบาท (ยอดต่างประเทศแปลงด้วยอัตรา USD/THB ของแต่ละวัน)
- ปันผลหุ้นไทยก่อนหักภาษี, ภาษีหัก ณ ที่จ่าย 10%, ประมาณเครดิตภาษีเงินปันผลถ้านำมารวมคำนวณ
- ปันผลต่างประเทศ, ภาษีที่ต่างประเทศหัก (US 15%), กำไรที่ขายแล้ว และยอดที่ต้องเสียภาษีถ้านำเงินเข้าไทย (กฎตั้งแต่ปี 2567)
- กำไรจากหุ้นไทยและกองทุน (ยกเว้นภาษีสำหรับบุคคลธรรมดา)
- SSF / RMF / Thai ESG: ยอดซื้อในปี, วงเงินลดหย่อน (30% ของเงินได้ ไม่เกิน 200,000 / 500,000 / 300,000 และ SSF+RMF รวมไม่เกิน 500,000), ยังลดหย่อนได้อีกเท่าไร, เตือนเมื่อขายก่อนครบระยะถือ (SSF 10 ปี, RMF 5 ปีและอายุ 55, Thai ESG 5 ปี)
- ตอนบันทึกปันผล มีปุ่มกรอกภาษีหัก ณ ที่จ่ายตามอัตราปกติ (ไทย 10%, US 15%)
- คัดลอกหรือดาวน์โหลดสรุปเป็นไฟล์ข้อความเพื่อใช้ยื่นภาษี

### 17. แผนลงทุนรายเดือน (DCA, แท็บ Plan)
- ตั้งแผน: พอร์ต, หุ้น/กองทุน, จำนวนเงินต่อเดือน (ในสกุลของสินทรัพย์), วันที่ 1–28
- เซิร์ฟเวอร์เช็กทุกชั่วโมง ถึงวันแล้วเตือนครั้งเดียวต่อเดือน (ในแอป + ntfy / Telegram / webhook)
- ปุ่ม "บันทึกการซื้อ": ดึงราคาวันนี้ คำนวณจำนวนหน่วยให้ แก้ได้ก่อนบันทึก แล้วสร้างรายการซื้อพร้อมอัตราแลกเปลี่ยนให้เอง
- หยุดชั่วคราว / ทำต่อ / แก้ / ลบ แผนได้

### 18. มือถือ
- บนจอเล็ก (แอป `mobile` และเว็บบนมือถือ) มีแถบเมนูด้านล่างแบบแอป: Dashboard, Portfolio, Watchlist, Markets และ "เพิ่มเติม" สำหรับหน้าอื่นทั้งหมด รองรับขอบจอ (safe area) และย้าย toast ให้อยู่เหนือแถบเมนู
- **การแจ้งเตือนของระบบ** (Settings → การแจ้งเตือนราคา): เปิดแล้วแอปจะขออนุญาตและแสดง alert / การเตือน DCA / รายงาน เป็นการแจ้งเตือนของเครื่องขณะแอปเปิดอยู่เบื้องหลัง ส่วนการแจ้งเตือนตอนปิดแอปใช้ ntfy หรือ Telegram ได้ตามเดิม

## ฟีเจอร์ที่เสนอ

ฟีเจอร์ที่เคยเสนอไว้ทั้งหมด (โหมดออฟไลน์, ภาษีแบบไทย, template CSV ของโบรกเกอร์, เตือน DCA, alert ทางเทคนิคัล, สินทรัพย์ประเภทอื่น, รายงานประจำเดือน, แอปมือถือ) ทำแล้วตามข้อ 2, 10, 11, 14–18 ข้างบน

ข้อจำกัดที่ยังเหลือ:

| เรื่อง | รายละเอียด |
|---|---|
| Push notification แบบ native บนมือถือ | แอป `mobile` ใช้การแจ้งเตือนของระบบผ่าน WebView ได้เฉพาะตอนแอปเปิดอยู่ (บาง WebView บน Android ไม่รองรับ) การแจ้งเตือนตอนปิดแอปยังต้องใช้ ntfy / Telegram เพราะ push แบบ native ต้องมีโค้ดเฉพาะแพลตฟอร์ม (FCM / APNs) |
| ไฟล์ CSV ของโบรกเกอร์ | preset อิงรูปแบบ export ที่พบบ่อย ถ้าโบรกเกอร์เปลี่ยนชื่อคอลัมน์ ให้ใช้โหมด "โบรกเกอร์ใดก็ได้" ซึ่งจับคอลัมน์จากชื่อหัวตาราง |
| กฎภาษี | ตัวเลขในการ์ดภาษีไทยใช้ประกอบการตัดสินใจเท่านั้น วงเงินและระยะถือกองทุนลดหย่อนเปลี่ยนได้ตามประกาศกรมสรรพากร |
