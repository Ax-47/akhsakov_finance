# Thesis และการเชื่อมต่อ Claude

## Thesis คืออะไรในแอปนี้

ทุกหุ้นในแต่ละพอร์ตมี thesis ของตัวเอง (หุ้นตัวเดียวกันในสองพอร์ตมี thesis แยกกันได้)

| ช่อง | ความหมาย |
|---|---|
| ทำไมถึงถือ | เหตุผลที่ซื้อ |
| จะขายถ้า… | สิ่งที่จะพิสูจน์ว่าคิดผิด หรือเงื่อนไขขาย |
| ราคาเป้าหมาย | ต่อหุ้น เป็น USD |
| ความมั่นใจ | 1–5 |
| ทบทวนวันที่ | ถึงวันแล้วแถวนั้นจะขึ้นป้าย "ถึงเวลาทบทวน" |
| สถานะ | ตามเป้า / มีความเสี่ยง / ผิดไปแล้ว |
| บันทึกติดตาม | บันทึกสั้นๆ มีวันที่กำกับ เช่น ผลงบ ข่าว หรือผลการทบทวน |

ที่ที่ใช้ได้:

- **หน้าพอร์ต → แท็บ Thesis**: หุ้นทุกตัวในพอร์ต เรียงจากต้นทุนมากไปน้อย กดแถวไหนก็แก้ของตัวนั้นได้ ถ้าเลือก "หุ้นทั้งหมด" จะแยกเป็นส่วนตามพอร์ต หุ้นที่ขายหมดแล้วแต่ยังมี thesis จะขึ้นป้าย "ไม่ได้ถือแล้ว" โดยประวัติยังอยู่ครบ
- **หน้าหุ้นรายตัว → Summary**: การ์ด "Thesis ของคุณ" แสดงหนึ่งแถวต่อหนึ่งพอร์ตที่ถือหุ้นตัวนั้น

ทุกอย่างที่ AI เขียนจะมีป้าย **AI** กำกับ เวลา AI แก้ช่องไหน ระบบจะจดลงบันทึกติดตามให้เองว่าแก้อะไรจากค่าไหนเป็นค่าไหน การแก้ของเราเองจะไม่ถูกจดลงบันทึก

Thesis อยู่ในไฟล์ฐานข้อมูลเดียวกับข้อมูลอื่น จึงติดไปกับ Backup ด้วย ถ้าลบพอร์ต thesis ของพอร์ตนั้นจะถูกลบตามไปด้วย

## เชื่อมต่อ Claude (ใช้กับ Claude Pro ได้)

แอปมี MCP server อยู่ที่ `/mcp` ซึ่งเป็นมาตรฐานที่ Claude ใช้ต่อกับเครื่องมือภายนอก

1. เปิด **Settings → เชื่อมต่อ Claude → เปิดใช้** ระบบจะสร้างคีย์ส่วนตัวให้
2. กด Copy แล้วนำไปวางใน Claude ตามวิธีด้านล่าง

| ใช้ Claude ผ่าน | วิธี |
|---|---|
| claude.ai / แอป Claude (Pro) | Customize → Connectors → Add custom connector แล้ววาง URL `https://<ที่อยู่>/mcp/<คีย์>` ช่อง OAuth เว้นว่าง |
| Claude Code | `claude mcp add --transport http akhsakov <ที่อยู่>/mcp --header "Authorization: Bearer <คีย์>"` |
| Claude Desktop (ต่อกับเครื่องตัวเอง) | Settings → Developer → Edit Config แล้วเพิ่ม `mcp-remote` ตามที่หน้า Settings ให้มา ต้องมี Node.js |

**claude.ai ต้องใช้ที่อยู่ https ที่เข้าถึงได้จากอินเทอร์เน็ต** เพราะ Claude เชื่อมต่อมาจากเซิร์ฟเวอร์ของ Anthropic จึงมองไม่เห็น `127.0.0.1` ในเครื่องเรา วิธีที่ง่ายคือเปิด tunnel มาที่แอป เช่น

```sh
cloudflared tunnel --url http://127.0.0.1:8080      # ได้ https://xxxx.trycloudflare.com
# หรือ
tailscale funnel 8080
```

จากนั้นแก้ช่อง "ที่อยู่ที่ Claude ใช้" ในหน้า Settings เป็นที่อยู่ https นั้นก่อนกด Copy ส่วน Claude Code และ Claude Desktop ในเครื่องเดียวกันใช้ `http://127.0.0.1:8080` ได้เลย

### เครื่องมือที่ Claude ได้

| เครื่องมือ | ทำอะไร |
|---|---|
| `list_portfolios` | พอร์ตทั้งหมด หุ้นที่ถือ จำนวน ต้นทุน สัดส่วนตามต้นทุน วันที่ซื้อครั้งแรก และสถานะ thesis (อ่านอย่างเดียว) |
| `list_theses` | thesis ทั้งพอร์ตพร้อมบันทึกล่าสุด หุ้นที่ยังไม่มี thesis และตัวที่ถึงเวลาทบทวน (อ่านอย่างเดียว) |
| `get_thesis` | thesis เต็มของหุ้นหนึ่งตัว บันทึกทั้งหมด และโน้ตส่วนตัวของหุ้นตัวนั้น (อ่านอย่างเดียว) |
| `save_thesis` | สร้างหรือแก้ thesis แก้เฉพาะช่องที่ส่งมา ถ้าส่ง `null` คือล้างช่องนั้น |
| `add_thesis_note` | เพิ่มบันทึกติดตาม |

ตอนเชื่อมต่อ แอปจะส่งคำแนะนำให้ Claude ว่าต้องเรียก `get_thesis` ก่อนคุยเรื่องหุ้นตัวไหน ให้จดสิ่งที่ได้เรียนรู้ลงบันทึก และห้ามแก้ thesis เองโดยที่ผู้ใช้ไม่ได้ขอ Claude จึงจำเหตุผลการลงทุนของเราได้ข้ามแชท

ตัวอย่างคำสั่ง: "ทบทวนพอร์ต Portfolio1 ให้หน่อย ตัวไหน thesis เริ่มไม่เป็นไปตามที่คิด", "NVDA ประกาศงบแล้ว เช็กกับ thesis แล้วจดไว้ให้ที"

### ความปลอดภัย

- ถ้ายังไม่กดเปิดใช้ `/mcp` จะตอบ 404 เสมอ
- ทุกคำขอต้องมีคีย์ จะใส่ไว้ใน URL หรือใน header `Authorization: Bearer` ก็ได้ ใครได้คีย์ไปจะอ่านพอร์ตและแก้ thesis ได้ (แต่แก้รายการซื้อขายหรือลบพอร์ตไม่ได้) ถ้าคีย์หลุดให้กด "สร้างคีย์ใหม่" คีย์เก่าจะใช้ไม่ได้ทันที
- หน้า Settings ที่แสดงคีย์ต้องเข้าสู่ระบบก่อน (เมื่อสร้างบัญชีแล้ว)
- ไฟล์ Backup ไม่มีคีย์ติดไปด้วย และการ Restore จะไม่ทับคีย์ที่ใช้อยู่
- เปิดดูได้ใน Claude ว่ามันเรียกเครื่องมือตัวไหน และตั้งให้เครื่องมือเขียน (`save_thesis`, `add_thesis_note`) ต้องกดอนุญาตทุกครั้งได้
